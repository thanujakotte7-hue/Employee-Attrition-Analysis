# HR Employee Attrition Dashboard

## 📌 Project Overview
This project is an interactive HR Employee Attrition Dashboard developed using Microsoft Power BI as part of the SkillCraft Technologies Data Analytics Internship (Task 3).

## Objective
Analyze employee attrition and identify the key factors influencing employees to leave the organization.

## Dashboard Features
- Total Employees KPI
- Attrition Count KPI
- Attrition Rate KPI
- Department-wise Attrition
- Age Group Analysis
- Gender-wise Attrition
- Interactive Slicers
  - Department
  - Age Group
  - Gender

## Tools Used
- Microsoft Power BI
- Microsoft Excel (CSV Dataset)

## Key Insights
- Overall attrition rate is approximately 16%.
- Employees working overtime tend to have higher attrition.
- Research & Development has the highest employee attrition.
- Employees aged 26–35 show the highest turnover.
